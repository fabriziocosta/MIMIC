# MIMIC for Images workspace

The image workflow guide is maintained in [the project documentation](../docs/IMAGE_WORKFLOWS.md).

This directory contains the image workflow notebooks. Open them from the
repository root so their relative paths resolve correctly:

1. `01_download_and_filter.ipynb` prepares an image dataset.
2. `02_fit_mimic_embeddings.ipynb` fits MIMIC and saves embeddings.
3. `03_visualise_2d_images.ipynb` explores image layouts.
4. `04_smote_embedding_synthesis.ipynb` synthesizes from embeddings.
5. `05_iterated_mimic_embeddings.ipynb` fits stacked embeddings.
6. `06_iterated_smote_synthesis.ipynb` synthesizes from stacked embeddings.
